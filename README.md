# Klavye Altina Dusen Kirinti Nufus Sayimi

> Turkiye Cumhuriyeti Klavye Alti Istatistik Mudurlugu resmi yazilimi.
> Kabul etmeyenler de sayilir, sadece suratlari asik olur.

Bu depo, klavyenizin altinda yasadigi halde nufusa kayitli olmayan
kirinti toplumunun **ilk ve son** resmi sayimini gerceklestirir.

Bilimsel dayanak: klavyeyi kaldirinca birseyler var. O birseyler vatandastir.

## Neden bu kadar ciddi?

Cunku kola dokulmus cips kiritisi da temel haklara sahiptir:
- tus arasi serbest dolasim
- space tusu altinda konut dokunulmazligi
- enter tusuna basilinca firar etme ozgurlugu
- vergi numarasi (odeme zorunlulugu tartismalidir)

## Kurulum

```bash
python3 sayim.py
```

Baska bagimlilik yoktur. Kirintilar zaten yeterince bagimlidir.

## Ornek cikti

Program her calistiginda yeni bir sayim heyeti olusturur,
rasgele soyad, meslek ve ikamet durumu atar, vergi numarasi basar.
Sonra damga vurur. Damga gercektir. Murekkep hayalidir.

## Sikca sorulmayan sorular

**Bu yasal mi?**  
Mudurluk kendi kendini kurdugu icin evet.

**Patates var mi?**  
Yok. Yasak. Kirinti ekmek soyundandir.

**Siyaset var mi?**  
Hayir. (Evet, ama bakma.)
